# 画面実装向けチェックリスト

画面・フォーム・コンポーネントを実装したときに当てる観点リスト。
`qa-test-design` のチェックリスト照合で参照する。

対象に当てはまる項目を列挙し、それぞれを観点としてテストケースに変換する。

## 表示・レンダリング
- [ ] 初期表示が仕様通りか（タイトル／プレースホルダー／デフォルト値）
- [ ] ローディング中の表示（スケルトン／スピナー／ボタン無効化）
- [ ] 空状態（empty state）の表示
- [ ] エラー状態の表示（API失敗・バリデーション失敗・ネットワーク断）
- [ ] 長文・長い名前で崩れないか（オーバーフロー、改行、省略）
- [ ] モバイル表示で崩れないか（狭い幅、タッチ領域）
- [ ] ダークモード／テーマ切替で崩れないか（該当する場合）
- [ ] console error / warning が出ていないか

## 入力・バリデーション
- [ ] 必須項目が未入力のときエラーが表示されるか
- [ ] 形式エラー（メール／電話番号／日付）が検出されるか
- [ ] 文字数の境界（max ちょうど、max+1）
- [ ] 全角／半角の混在入力（数字・記号・スペース）
- [ ] 絵文字・サロゲートペア・ゼロ幅文字
- [ ] 改行・タブ・前後空白のトリム挙動
- [ ] 貼り付け時の整形（クリップボード経由の異常値）

## 操作・送信
- [ ] 二重送信できないか（連打、Enter連打、ネットワーク遅延中の再クリック）
- [ ] 送信中にフォームを編集／別画面遷移したらどうなるか
- [ ] ブラウザの「戻る」で再送信されないか
- [ ] キャンセル操作（×ボタン／ESC／戻る）で状態が壊れないか
- [ ] 確認ダイアログのキャンセルが効くか

## API連携・状態
- [ ] API失敗時にUIが壊れないか（白画面・ボタン押せないなど）
- [ ] ネットワーク断・タイムアウト時のフィードバック
- [ ] 「保存成功」と表示されたが実データが反映されていない、というケースがないか
- [ ] 楽観的更新（optimistic update）の場合、失敗時にロールバックされるか
- [ ] ページ離脱時の未保存警告（dirty チェック）

## 権限・認可
- [ ] 権限がないユーザーに操作ボタンが見えていないか／無効化されているか
- [ ] URL直叩きでアクセスできないか
- [ ] ログアウト中に保護された操作ができないか

## 一致性・整合性
- [ ] 一覧と詳細でデータが一致しているか
- [ ] 楽観ロック／同時編集の挙動（他タブで編集された場合）
- [ ] ページネーション境界（1ページ目／最終ページ／空ページ）
- [ ] ソート・フィルタの組み合わせ
- [ ] 件数 0 件、1件、N件、大量件数（仮想スクロール境界）

## アクセシビリティ・国際化
- [ ] キーボード操作のみで完結するか（Tab順、Enter/Space）
- [ ] スクリーンリーダーでの読み上げ（aria-label, role）
- [ ] フォーカスの可視化と遷移
- [ ] 言語切替（i18n）で文字数が増えても崩れないか
- [ ] 日付・通貨・数値のロケール表示

## ブラウザ・環境
- [ ] 主要ブラウザ（Chrome / Safari / Firefox / Edge）
- [ ] iOS Safari の独自挙動（input zoom、スクロール）
- [ ] 低速回線（throttling）での挙動
