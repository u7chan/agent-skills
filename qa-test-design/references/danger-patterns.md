# 危険パターン集（エラー推測の引き出し）

過去のプロダクト障害でよく見るパターン。
`qa-test-design` のエラー推測で参照する。観点出しのとき必ず照合する。

各項目について、対象の実装に **当てはまるかどうか** を一度問う。
当てはまるなら、具体的なテストケースに落とし込む。

## 送信・操作系

### 二重送信
- ボタン連打 → 同じ注文が2件作成される
- Enter連打 / フォーム連打
- ローディング中に再クリックできてしまう
- → 観点: ボタンの disable、サーバー側の冪等キー

### 戻る操作後の再送
- 完了画面から戻るボタン → フォーム再送信
- POST後のリロード（F5）で再送
- → 観点: PRG パターン（Post-Redirect-Get）の実装

### キャンセル中の操作
- 送信中にキャンセル／別画面遷移
- リクエストは飛んでいるが UI 側ではキャンセル扱い
- → 観点: AbortController、サーバー側の処理結果と UI の整合

## データ・型系

### null と空文字の混在
- 「未入力」を null で表すか "" で表すかが層ごとに違う
- DB は null、API は ""、画面は undefined のような不揃い
- → 観点: 各境界での変換ルールを明示してテスト

### 全角／半角の混在
- 数字の全角入力（１２３）
- 半角カナ
- 全角スペース、ノーブレークスペース
- → 観点: 正規化のタイミングと、検索・比較への影響

### 絵文字・サロゲートペア
- DB の文字コード（utf8mb3 vs utf8mb4）
- 文字数カウントが「コードユニット」か「グレファイム」か
- → 観点: 入力上限、表示の崩れ、検索

### ゼロ幅文字・制御文字
- コピペで紛れ込むゼロ幅スペース
- BOM 付きの貼り付け
- → 観点: トリム・正規化

### 改行・タブ
- 名前欄に改行を入れて崩す
- CSV 出力時のインジェクション
- → 観点: 入力時の禁則 or 出力時のエスケープ

## 時刻・地域

### タイムゾーン差分
- サーバーが UTC、クライアントが JST
- 日付の境界（00:00 ちょうど）でズレる
- 集計の「今日」が UTC 基準でズレる
- → 観点: 23:59 / 00:00 / 00:01 の境界、DST のある地域

### 日付フォーマット
- `2026/05/07` と `05/07/2026` と `7/5/2026` の取り違え
- ISO 8601 と独自フォーマットの混在
- → 観点: パースの厳密さ

### 閏年・閏秒
- 2/29 を含む期間計算
- → 観点: 4年に1度の特殊日

## 権限・認可

### 権限の抜け道
- ボタンを非表示にしただけで API は叩ける
- URL 直叩きで他人のリソースが見える（IDOR）
- 管理画面のエンドポイントが認証なし
- → 観点: 認可は必ずサーバー側で

### ロールの境界
- 「読み取り専用」ロールが書き込みエンドポイントを叩けてしまう
- 退職者のトークンが残っている
- → 観点: ロール × 操作の網羅

## 通信・状態

### 通信失敗時の中途半端な状態
- 「保存しました」表示が出たのに DB には反映されていない
- 楽観的更新の失敗ロールバック漏れ
- → 観点: ネットワーク断の再現テスト、500 エラーの再現

### タイムアウトと再送
- クライアントがタイムアウトで再送 → サーバーは1回目を処理中
- 結果として2回処理される
- → 観点: 冪等キー、サーバー側の処理時間

### リトライの暴走
- 失敗時のリトライがバックオフなしで連発
- 障害中の DB に追い討ち
- → 観点: 指数バックオフ、サーキットブレーカー

## 整合性

### 「成功表示」と「実データ」の乖離
- フロントでは成功扱いだが API 側は非同期ジョブで失敗
- → 観点: ジョブ失敗時の通知、再表示時の整合確認

### 楽観ロック
- 他タブで編集 → こちら側で保存
- 上書きしてしまう／コンフリクト検知できない
- → 観点: バージョン番号 or updated_at の比較

### 削除済み・論理削除
- 削除済みレコードが一覧に出てしまう
- 削除済みを参照する FK の挙動
- → 観点: WHERE deleted_at IS NULL の漏れ

## 数値・計算

### 浮動小数点
- 0.1 + 0.2 ≠ 0.3
- 金額計算で誤差
- → 観点: 整数（最小単位）or Decimal型での計算

### オーバーフロー / アンダーフロー
- 32bit 整数の上限
- カウンタの増加
- → 観点: 大きな値の境界

### ゼロ除算
- 平均値計算で件数が 0
- → 観点: 分母 0 の前置チェック

## ファイル・アップロード

### サイズ・MIME
- 巨大ファイル
- 拡張子と中身の不一致（.jpg なのに実体は .exe）
- → 観点: サーバー側でのバイナリチェック

### パストラバーサル
- ファイル名に `../` を含めて任意パスに保存
- → 観点: サニタイズ、固定ディレクトリ + 生成ID

## SQL・クエリ

### N+1
- ループ内で個別クエリ
- → 観点: 件数を増やしたときの応答時間

### 大量結果
- LIMIT なしの SELECT
- → 観点: ページネーションの強制

### トランザクション境界
- 複数テーブル更新の途中で失敗
- → 観点: 一貫性の確認
