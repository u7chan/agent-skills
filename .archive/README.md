# Archived Skills

廃止したスキルを、履歴保持のために保管するディレクトリです。

現在、Herdr への移行に伴って廃止した `tmux-*` スキルを保管しています。

## 運用ルール

- 廃止するスキルは、ディレクトリ単位で `.archive/` 配下へ移動する。
- 配下のスキルは利用・保守対象外とし、ルート README の `Available Skills` には掲載しない。
- 通常のスキル検証では `.archive/` 配下を対象外とする。
- アーカイブしたスキルは直接修正・参照しない。
- 再利用する場合はリポジトリ直下へ戻し、README と参照元を更新してから検証する。
