## 1. 空間的一貫性

- 表示と非表示で同じ経路を使う。右から現れたパネルは右へ戻す。
- メニュー、ポップオーバー、シートを開いたトリガーと空間的に結び付ける。
- `transform-origin`をトリガー側へ寄せ、どこから来たかを示す。
- 反転可能な遷移では行きと戻りの軌道を一致させる。
- イージングを使う場合は、逆方向で対応する三次ベジェを使い、速度の連続性も確認する。

経路を変える必要がある場合は、情報構造の変化や物理的な制約など、ユーザーが理解できる理由を持たせる。

## 2. 軌道で意図を示す

中間フレームは開始値と終了値の補間ではなく、向かう先を伝える。

- 展開する要素は、操作方向や起点へ沿って成長させる。
- 関係する子要素は、最終配置へ向かう軌道を早い段階から示す。
- 複数要素の遅延は装飾的なstaggerではなく、因果関係や読み順を表す場合だけ使う。
- 途中の形が別の状態に誤認されないか、低速再生で確認する。

## 3. 半透明マテリアル

半透明面を、主コンテンツから注意を奪わず階層を作る浮遊レイヤーとして使う。

```css
.toolbar {
  background: rgb(255 255 255 / 60%);
  backdrop-filter: blur(20px) saturate(180%);
  border-top: 1px solid rgb(255 255 255 / 40%);
}
```

- ナビゲーション、ツールバー、シートは、必要に応じてコンテンツが下を通るレイヤーとして構築する。
- 半透明を使う理由がなければ不透明面を選ぶ。blurは無料ではない。
- 暗く重いマテリアルで構造領域を分離し、明るく軽い面で操作要素を前へ出す。
- 明るい半透明面の上へ、さらに明るい半透明面を重ねない。可読性と輪郭が失われやすい。
- 大きな面は小さなチップより強いblurと深い影を試し、背景の複雑さに応じて調整する。
- backdrop-filter非対応時にも読める背景色を先に指定する。

## 4. 奥行きとモーダリティ

- 集中が必要なモーダルではscrimを置き、背景を暗く、必要ならわずかに奥へ押す。
- 並行利用できる非ブロッキングパネルではscrimを避け、位置、半透明、面差で分離する。
- シートを積む場合は、親を段階的に暗くし、奥へ押して階層を示す。
- 背景を操作不能にする場合は、見た目だけでなくフォーカス移動、読み上げ順、escape / closeも整合させる。
- 影の強さは背景の複雑さと面の大きさに合わせる。

## 5. バイブランシーと区切り

変化する背景の上では、単純な半透明グレー文字だけに頼らない。

- コントラストを高め、必要ならウェイトを少し上げ、字間を微調整する。
- 色は半透明の文字レイヤーではなく、安定した不透明レイヤーへ置くことを検討する。
- 固定ヘッダーの下へ常時1px線を置く前に、重なる箇所だけのblur、shadow、gradient maskを検討する。
- 透明度を使った見た目を、実際の背景画像・動画・ライト／ダークテーマで検証する。

## 6. マテリアルの遷移

ガラス面を単にfadeさせず、素材が形成・解消されるようにblur半径、scale、opacityを協調させる。

- 変化量を抑え、主コンテンツより注意を奪わない。
- blurのアニメーションが高コストなら、擬似要素や事前に合成した面を使う。
- reduced transparencyでは不透明面へ置き換える。
- reduced motionではscaleや大きな移動を外し、短いcrossfadeまたは静的切り替えにする。

## 7. タイポグラフィ

### オプティカルサイズとトラッキング

- まず`system-ui`を使い、カスタムフォントは明確な理由がある場合だけ採用する。
- 可変フォントが対応する場合は`font-optical-sizing: auto`を使う。
- すべてのサイズへ同じ`letter-spacing`を適用しない。
- 大きなdisplay文字は負のtracking、小さな文字は可読性のためわずかに正のtrackingを検討する。
- 見出しは詰め、本文は`0`付近から調整する。

### リーディングと階層

- 大きな見出しでは行間を詰め、本文では広げる。
- アセンダーやディセンダーが大きい文字体系では余裕を増やす。
- 階層をサイズだけで作らず、ウェイト、サイズ、行間、余白を組み合わせる。
- 強調には面積を増やしにくいウェイトを使うが、太字過多を避ける。

### 文字サイズへの適応

- 余白とコンポーネント寸法を`rem`や`em`で連動させる。
- 拡大時に切り詰め、固定高、重なり、操作不能が起きないか確認する。
- 行長、折返し、見出しの複数行化を実際のコンテンツと翻訳で検証する。

```css
:root {
  font: 100%/1.5 system-ui, sans-serif;
}

.display {
  font-size: clamp(2rem, 5vw, 4rem);
  line-height: 1.05;
  letter-spacing: -0.02em;
  font-optical-sizing: auto;
}
```

`-0.02em`は大きな文字向けの出発点であり、書体と文字体系ごとに目視確認する。
