# Image to SVG 変換

参照画像を、視覚的に一致する編集可能 SVG に変換する。ネイティブ SVG 要素（`<rect>`, `<path>`, `<text>`, `<linearGradient>`, `<filter>` 等）で構成し、ラスター画像の埋め込みは最小限に留める。最後にレンダリング比較を行い、修正サイクルを回してから納品する。

## 必須ルール

- **画像全体の `<image>` 埋め込みは禁止**。個別要素で再構築する
- **テキストは編集可能な `<text>` 要素として残す**（パス化禁止）
- **図形は個別の要素として記述**（単一パスへのフラット化禁止）
- **`<g>` グループと `id` 属性で構造化**する
- **生成後にレンダリング比較→修正サイクルを最低 1 回回す**。一発納品禁止
- 再構築困難な要素のみ、個別の小さな PNG/JPEG を `<image>` 要素で挿入してよい（部分用途のみ、画像全体は不可）

## 適用範囲

スライド、イラスト、アイコン、抽象アート、ロゴ、UI モック等、参照画像が存在するあらゆる対象。テキストの有無、図形の複雑さ、グラデーションや影の有無に関わらず本手順を適用する。

## 手順

### 手順1: 元画像の要素分解

画像内の全要素をリストアップする。観点:

- 背景・装飾
- 主要な図形・オブジェクト
- アイコン・イラスト
- テキスト（あれば）
- 装飾要素（点、線、模様、ぼかし等）

要素間の重なり順（z-order）を意識し、後で SVG 内に書く順番に対応させる。

### 手順2: 要素ごとの描画方式

| 要素 | 推奨実装 |
|---|---|
| テキスト | `<text>`（行分割は `<tspan>`） |
| 矩形・帯・カード・背景 | `<rect>`（角丸は `rx`/`ry`） |
| 円・楕円 | `<circle>` / `<ellipse>` |
| 直線・罫線 | `<line>` |
| 曲線・自由形状・アイコン | `<path>`（ベジェ曲線で再構築） |
| グラデーション | `<linearGradient>` / `<radialGradient>`（`<defs>` 内に定義） |
| 影・ぼかし | `<filter>`（`feGaussianBlur`, `feOffset`, `feMerge` 等） |
| パターン（ドット・ストライプ） | `<pattern>` |
| 透明・マスク | `opacity`, `<mask>`, `<clipPath>` |
| 再構築困難な小要素のみ | 切り出した PNG/JPEG を `<image>` で挿入（部分用途） |

禁止: 画像全体の `<image>` 貼り付け、テキストのパス化、全要素の単一パス結合。

### 手順3: アイコン・複雑形状の SVG 化

- 各オブジェクトを個別の `<g id="...">` でグループ化
- シンプルな幾何形状は `<path>` のベジェで再構築
- 制御点は元画像から目視推定（ピクセル座標→viewBox 座標へスケール）
- ベジェで再現困難な細密イラストに限り、その要素のみ `<image>` 挿入を許可（画像全体ではない）

### 手順4: SVG サイズと viewBox

- **viewBox は元画像のピクセル比率に合わせる**（例: 320×320 → `0 0 320 320`、1920×1080 → `0 0 1920 1080`）。固定値での決め打ちはしない
- ルート要素に `xmlns="http://www.w3.org/2000/svg"` を必ず指定
- レスポンシブ表示のため `width` / `height` は省略するか `100%` 指定

### 手順5: テキストの転記（テキストが存在する場合のみ）

画像中にテキストが無い場合、本手順はスキップして手順6へ。

- 誤字なし、全角・半角・数字・単位・句読点を元画像と一致
- `font-family`, `font-size`, `font-weight` を明示
- 日本語フォントは `'Noto Sans JP', 'Hiragino Sans', 'Yu Gothic', sans-serif` 等のフォールバック指定
- 英数字フォントは `'Helvetica Neue', Arial, sans-serif` 等のフォールバック指定
- 意図しない折り返しが起きない位置・幅で配置

### 手順6: 色とスタイル

- 16 進カラーコードで明示指定
- 元画像から目視サンプリング（必要なら `gimp`、ブラウザ DevTools のスポイト等を使ってもよい）
- 透明度は `fill-opacity` / `stroke-opacity` または `rgba` で指定
- 線幅は元画像との整合を優先（細線 1〜2、太線 4〜10 等を viewBox 単位でスケール調整）

### 手順7: レンダリング

PNG 化または直接表示で確認する。優先順:

1. `rsvg-convert -w <元幅> output.svg -o rendered.png`（高速、推奨）
2. `inkscape --export-type=png --export-width=<元幅> output.svg`
3. Chrome / Firefox で SVG を開いて手動スクリーンショット
4. Headless Chrome（`google-chrome --headless --screenshot=...`）

**いずれも実行不能な環境では、SVG をブラウザで開き目視チェックでも可**。レンダリング不能を理由に手順8〜9をスキップしてはならない（目視差分でも比較・修正は実施する）。

### 手順8: 比較チェックリスト

レンダリング結果（または SVG 直接表示）と元画像を目視比較する。汎用チェック項目:

- 各要素の位置・サイズ・比率
- 色・グラデーションの方向と停止色
- 線の太さ・スタイル
- テキストの内容・フォント・サイズ・配置（テキストがある場合）
- 余白・整列
- 透明度・影・ぼかしの再現度
- 意図しない要素の欠落・余分

### 手順9: 修正と再レンダリング

- 最低 1 回は修正サイクルを回す
- 明らかな崩れがある状態で納品しない
- 修正→再レンダリング→比較を、目視差分が許容範囲に収まるまで繰り返す

### 手順10: SVG 内部の最終監査

納品前に確認:

- 画像全体の `<image>` 埋め込みなし（部分用途のみ可）
- `<text>` 要素がパス化されていない
- 図形が個別要素として記述されている
- `xmlns` が正しく指定されている
- ブラウザで開いて表示崩れがない
- テキストエディタで開いて該当文字列・色・座標を直接編集できる

## 納品物

- 編集可能 SVG ファイル 1 点
- 画像全体のラスター埋め込みなし
- テキスト編集可能（`<text>` 要素として残存）
- 図形が個別要素として選択・編集可能
- 元画像との大きな崩れなし
- レンダリング比較→修正サイクルを最低 1 回実施済み
