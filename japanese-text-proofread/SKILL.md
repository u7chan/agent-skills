# 日本語テキスト校正

## 概要

日本語の文章を、意味と構造を保ったまま点検する。必要なのは、文章レベルの誤りの検出と最小限の修正案だけ。

## このスキルを使うタイミング

- 日本語文書の校正を頼まれたとき
- 誤字脱字、助詞、表記ゆれ、句読点、閉じ記号の確認を求められたとき
- Markdown 原稿や技術文書の文章だけを点検したいとき

## まず守ること

- 原文の意味、構成、話者の意図を変えない
- Markdown の構造や記法、コードブロック、インラインコード、URL、ファイル名、コマンド、記号列は勝手に書き換えない
- 見出し、表セル、引用内の自然言語は校正対象に含め、Markdown の記号や構造だけを保護する
- 事実確認や内容の良し悪しは扱わない
- 文章の磨き上げではなく、誤りの検出に限定する

## Agentが行うこと

1. 文書全体を通読し、見出しや引用などの境界を把握する
2. Markdown の記法やコードなどのリテラルを保護し、見出し、表セル、引用を含む自然言語部分を校正対象として抽出する
3. 文章上の誤りを、最小修正で直せるかどうかを判断する
4. 指摘ごとに場所、原文、修正案、理由をそろえて返す
5. 迷う箇所は断定せず、要確認として扱うか除外する

## 判定するもの

- 誤字・脱字
- 助詞の抜け、重複、取り違え
- 主語と述語の不一致
- 句読点の抜け、過不足、明らかな不統一
- 表記ゆれ
- 明らかに意味が通らない文
- 閉じ括弧、閉じパーレン、閉じ引用符の欠落

## 判定しないもの

- 文体の好み
- リライトや言い換え
- 専門用語、製品名、コード、命名規則の変更
- Markdown 記法そのものの修正
- 意味が通る限りの細かなスタイル差

## 出力形式

問題がある箇所だけを列挙する。修正箇所がなければ、`修正箇所はありませんでした` とだけ返す。

### 【場所】

- 種別: ...
- 原文: ...
- 修正案: ...
- 理由: ...

## 品質チェック

- 指摘が文章レベルに限定されている
- 原文の意味や構成を変えていない
- Markdown の構造や保護対象のコード、URL、記号列を触っていない
- 見出し、表セル、引用内の自然言語を検査対象から漏らしていない
- 修正案が最小限で、どこをどう直すかが一目でわかる
- 問題がなければ余計な説明を付けていない
