## 概要
PR 本文のドラフトを作成するスキル。本文構造とガイドラインの一次情報は共通参照ファイルに集約し、このスキルはそのテンプレートに沿って内容を埋める役割に限定する。

## 参照ファイル

- 共通参照ファイル: `../.shared/pr-body-template.md`

## ワークフロー

### 1. 共通テンプレートを確認

まず共通参照ファイルを参照し、`Issues / Why / Summary / Changes / Checklist / Details` の構造とガイドラインを確認する。

### 2. コンテキストを確認

**重要: まだ git コマンドは実行しない。**

まず、会話内に十分なコンテキストがあるか確認する。

コンテキストが利用可能な場合:
1. 会話履歴から Issue 番号、変更内容、目的、検証結果が十分に取れると判断する
2. ステップ 3 に直接進み、すぐに PR 本文を作成する

コンテキストが不足している場合:
以下の git コマンドで補足情報を収集する。
- `git branch --show-current`
- `git log --oneline main..HEAD`
- `git diff --name-status main`

### 3. PR 本文を作成

ステップ 1 の共通テンプレートに従い、ステップ 2 で確認した情報を埋めて PR 本文を作成する。

- `Issues` は `Close` または `Refs` のどちらか適切な形式を選ぶ
- `Why` は背景と目的を 1〜3 段落で簡潔に書く
- `Summary` は PR 全体の要点を 2〜3 文でまとめる
- `Changes` は主要変更点だけを箇条書きにする
- `Checklist` は実施済みまたは確認対象の内容を現実に合わせて記述する
- `Details` は必要な場合だけ追加する

### 4. 出力形式

PR 本文全体を Markdown のコードブロックで囲って提示する。

## 注意

- テンプレート本文やガイドラインをこのファイルへ重複記述しない
- 会話内に完成済みの `PR_BODY` がある場合、このスキルを使わずその本文をそのまま流用してよい
- 本文構造を変更したい場合は共通参照ファイルを更新する
